# Saaho

A fresh, browser based toolkit for everyday work.

## Run locally

```sh
npm install
npm run dev
```

Build for production with `npm run build`.

The 24 tools are grouped into Everyday, Developer, Images, and Writing. Utilities run locally in the browser, including QR generation, JSON formatting, text helpers, image compression and resizing, color sampling, date and ratio calculations, and developer utilities. Saved tools and theme preference stay in local storage.
